# libSceAgcVsh technical debt

### Unknown function info

- [The 80 exports that return a libSceAgc function's result](../../../core/libs/prx/libSceAgcVsh/Export.cpp) (libSceAgcVsh) - forward to the libSceAgc function with the same NID. @BunnyFl's [static comparison of firmware 13.42's two modules](https://github.com/boykopovar/AnyPS5/issues/13815#issuecomment-6543804005) found 77 of these bodies byte-identical and 4 the same instructions at different addresses (`sceAgcAcbAcquireMemGetSize`, `sceAgcCreateInterpolantMapping`, `sceAgcLinkShaders` and `sceAgcUpdatePrimState`). Nothing was run, and the data that rip-relative operands point at wasn't compared. On the console VSH imports only libc and libkernel and carries its own copy. Here it links libSceAgc, so `sceAgcLinkShaders` and `sceAgcCreateInterpolantMapping` also run libSceAgc's shader ABI resolution in libSceAgcDriver, as they do for a title.
- [The 24 exports that throw "not allowed to be called from agc vsh"](../../../core/libs/prx/libSceAgcVsh/Export.cpp) (libSceAgcVsh) - in the same [comparison](https://github.com/boykopovar/AnyPS5/issues/13815#issuecomment-6543804005) each of these VSH bodies prints `line %d: %s() is not allowed to be called from agc vsh.` and executes `int $0x41`. Here each throws `std::runtime_error` with that message for its name; the line number isn't known, so it's left out.
- [The 46 exports that still throw through NotImplemented_nid_no_patch](../../../core/libs/prx/libSceAgcVsh/Export.cpp) (libSceAgcVsh) - keep their parameterless declarations. In the same [comparison](https://github.com/boykopovar/AnyPS5/issues/13815#issuecomment-6543804005) 40 have different instructions from libSceAgc's and 4 call VSH-local functions where libSceAgc calls `sceAgcDriver*` imports, so libSceAgc's bodies aren't known to answer for them. `sceAgcCbReleaseMem` traps only on a path inside a longer body. `sceAgcGetFusedShaderSize` is byte-identical in 13.42, but libSceAgc here has only its `_0080` version. All 150 names and NIDs come from the PS5 3.20 [export inventory](https://github.com/DNNDHH/PS5-3.20_Libs/blob/b2a77c09cd71c01f34c790cfbe98c751a13262ad/libSceAgcVsh.c); the 13.42 module exports 246 functions, which aren't all declared here.
